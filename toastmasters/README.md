# Avon Toastmasters website

A responsive club website using the official Toastmasters brand palette.

## Run locally

Requires Node.js 18 or newer. No npm packages are required.

```bash
npm start
```

Then open http://localhost:3000.

For automatic restarts while editing:

```bash
npm run dev
```

## Hosting

The site is also static-hosting friendly. GitHub Pages can serve `index.html`, `styles.css`, `script.js` and `favicon.svg` directly from this folder at:

https://tdbnz-coding.github.io/toastmasters/

The Node server is for local development or a Node-capable host; GitHub Pages itself does not run Node.js.

## Club details

The official Toastmasters club finder is linked for current meeting details and contact information. Add confirmed Avon meeting times, venue and club contact details before publishing those specifics.

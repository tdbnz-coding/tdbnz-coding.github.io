    What’s newVersion 9.0

    Version 9.0

    • Optional agenda builder and next-participant queue—the normal one-person timer remains the default.
    • Reusable custom timing presets.
    • Saved meeting templates for optional agenda queues.
    • Active unsaved timer recovery after refresh, closure or a browser crash.
    • Undo and a 30-day recycle bin for deleted results, cleared reports and unsaved resets.
    • Dedicated competition mode with locked contest timings and full-screen signal lights.
    • Print or Save PDF for the complete timing report.
    • Complete JSON backup and restore for meetings, settings, presets and templates.

    Version 8.2

    • Correct mobile brand order and cleaner full-screen timer.
    • Stronger iPhone, iPad and Android screen-awake support.
    • What’s new changelog added to Settings.

    Version 8.1

    • Installable TM Timing Desk PWA with offline timer support.
    • Toastmasters application icons for Apple, Android and computers.
    • Unsaved-time reset warning enabled by default.
    • High-visibility keyboard focus outline made optional.

    Version 8.0

    • Thirty-day accessibility and timer preferences.
    • Large text, high contrast, spoken cues, keyboard controls and wake lock options.

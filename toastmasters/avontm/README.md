# Avon Toastmasters — Christchurch

A redesigned, responsive website for Avon Toastmasters, Christchurch, using the Toastmasters brand palette.

## Node.js

Requires Node.js 18 or newer. No third-party npm packages are needed.

```bash
npm start
```

Open http://localhost:3000. The health endpoint is /health.

For development with automatic restart:

```bash
npm run dev
```

Run syntax checks:

```bash
npm run check
```

## Website contents

- Responsive one-page club website
- Meeting information, location, contact links and guest call-to-actions
- SEO title, description, canonical URL, Open Graph and Twitter metadata
- EducationalOrganization JSON-LD structured data
- sitemap.xml placeholder and robots.txt
- Accessible navigation and FAQ disclosures

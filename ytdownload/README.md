# tdbnz Video Download

GitHub Pages + GitHub Actions video downloader using yt-dlp.

## Setup

1. Upload all files to a GitHub repository
2. Enable GitHub Pages
3. Replace:
   - YOURUSERNAME
   - YOURREPO
   - YOUR_GITHUB_TOKEN

inside script.js

## GitHub Token Permissions

Your GitHub token must allow:
- Actions: Read and Write
- Workflows: Read and Write

## Downloading

1. Paste a video URL
2. Choose video or audio
3. Start download
4. Open Actions tab
5. Download file from Artifacts

Use only for content you own or are allowed to download.

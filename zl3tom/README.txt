ZL3TOM AMATEUR RADIO — GITHUB PAGES WEBSITE

This ZIP is the static GitHub Pages version. No Node.js or build command is required.

UPLOAD INSTRUCTIONS
1. Extract this ZIP.
2. Open the GitHub repository that hosts zl3tom.com.
3. Upload every file and folder inside ZL3TOM-GitHub-Pages to the repository root.
4. Commit the changes to the main branch.
5. In GitHub: Settings > Pages > Deploy from a branch.
6. Select main and /(root), then Save.
7. Keep the included CNAME file. It connects the Pages site to zl3tom.com.

The sitemap will be available at:
https://zl3tom.com/sitemap.xml

The website includes:
- Homepage and Flag Counter
- Responsive About photo gallery
- Radio Fun, QSL and Contact pages
- Seven amateur radio guides
- SEO metadata, structured data, robots.txt and sitemap.xml
- Compatibility copies of the former .html page addresses

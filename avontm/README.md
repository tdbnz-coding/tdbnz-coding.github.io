# Avon Toastmasters website

A responsive, multi-page Node.js website for Avon Toastmasters in Christchurch.

## Pages

- Home — club introduction and visitor call to action
- About Avon — club culture and approach
- Meetings — meeting schedule, venue and meeting activities
- What to expect — a guide to the meeting format
- Benefits — communication, speaking and leadership skills
- Visit — guest information and contact details
- How to join — a step-by-step guide from first visit to membership
- FAQ — detailed answers about visiting, meetings and membership

The meeting guide also explains common meeting roles, including Toastmaster of the Day, Timer, Introducer, Speaker, Evaluator, Grammarian, Table Topics roles and General Evaluator.

## Run locally

Requires Node.js 18 or newer. No npm packages are required.

```sh
npm start
```

Open http://localhost:3000. The server also provides a health endpoint at /health.

## Brand assets

The header and footer use the official Loyal Blue Toastmasters masthead logo supplied on Toastmasters International's official website template resource page. Use official brand portal assets and follow the current Toastmasters Brand Manual when changing branding.

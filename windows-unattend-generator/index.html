    Safe-use guide

    How to use an autounattend.xml file

    A Windows answer file can automate setup pages and selected configuration passes. A careful test run is essential.

    1. 1

      Choose settings

      Select your Windows edition, regional preferences, disk mode and account options.

    2. 2

      Review the XML

      Check the preview and build notes. Pay particular attention to disk number and partition mode.

    3. 3

      Download the file

      Save the generated file with the exact name autounattend.xml.

    4. 4

      Test before use

      Place it at the root of Windows installation media and test it in a virtual machine first.

    Important

    Know what automatic disk mode does

    Automatic disk mode instructs Windows Setup to wipe the target disk. The disk number can differ between computers and virtual machines. If you are unsure, keep “Choose disk during setup” selected.

    Windows unattended setup FAQ

    What is an autounattend.xml file?

    An autounattend.xml file is a Windows Setup answer file. It supplies selected installation settings automatically, such as language, disk, edition and account options.

    Where do I put autounattend.xml?

    For a typical clean installation, place autounattend.xml in the root of the bootable Windows installation USB drive. Test it in a virtual machine before using it on important hardware.

    Does this generator upload my settings?

    No. Generation happens locally in your browser. This static website does not submit the form or its values to a server.

    Can an unattended installation erase a disk?

    Yes. Automatic disk configuration can erase every partition on the selected disk. Confirm the disk number, keep backups, and use interactive disk selection whenever you are uncertain.

    Does an answer file activate Windows?

    No. You still need a valid licence for the edition you install. A product key in the answer file can select or configure an edition, but it does not provide a licence.
